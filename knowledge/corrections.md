# Журнал корекцій власника скіла

Лише дописуємо, нічого не видаляємо. Сюди потрапляють правила з живого відгуку на конкретні тексти. Скіл читає цей файл у фазі 1. Правила звідси сильніші за типові з довідника, але не скасовують жорстких заборон і мовної норми.

Формат запису:

```
## РРРР-ММ-ДД — <тема>

Відгук: <що не сподобалося в конкретному тексті>

Правило: <конкретна дія для редактора>

Сфера: <тип текстів, до яких застосовується; «усі» за замовчуванням>
```

Приклад запису (видали його, коли з’явиться перший справжній):

```
## 2026-10-11 — терміни в технічних текстах

Відгук: у документації для розробників скіл замінив «деплой» на «розгортання», і колеги не впізнали термін.

Правило: у текстах для розробників залишай усталений жаргон (деплой, реліз, мердж). Український відповідник додавай у дужках лише при першій появі, якщо читач може не знати терміна.

Сфера: технічна документація, описи PR
```
